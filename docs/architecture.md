# 構成と実装境界

React / TypeScriptが共通の画面、画面履歴、配置下書き、分割プレビューを担当します。Rustが保存、起動キー、OS操作前の検証、履歴候補を担当し、OSごとのアダプターへ絶対座標の移動要求を渡します。

## 配置データ

`LayoutDocument` はモニターごとの分割木です。葉が領域、内部節が軸と親領域内の比率です。複数の割り当てが同じ葉を参照すれば完全同一矩形のStackになります。分割線の比率は独立し、子孫の最小寸法を守る範囲に制限します。最大9領域、深さ12以下です。

配置下書きと保存済み配置は分離しています。保存済み初期配置の更新には明示フラグを要求し、適用・候補生成・履歴削除では変更しません。旧形式の任意矩形はfreeformとして維持します。

## ネイティブ連携

macOSは同梱のSwift補助実行ファイルとJSON linesで通信します。AXUIElement参照は補助プロセス内に保持し、一覧の添字をウィンドウIDに使いません。反映前にPID・タイトルを照合し、Rust側もアプリIDと構成を照合します。移動後の実測矩形を返し、画面移動による非同期制約を考慮した短い再試行を行います。

WindowsはWin32 / DWMでウィンドウ・作業領域を列挙し、DPI awarenessを有効にした座標で移動します。ネイティブ全画面はアプリ共通APIがないため明示的に非対応とします。

ハブ表示前に前面ウィンドウと最大重なり面積のモニターを取得し、ハブへフォーカスが移った後も保持します。マウス位置は参照しません。閉じた際のフォーカス復帰はOS制約下でのbest effortです。

## 履歴候補

最大200件のJSON履歴を保存します。タイトルを除去し、アプリID・同アプリ内順序・モニター構成・矩形・時刻・記録元を保持します。同じ配置が2回以上あり、現在開いているアプリに一致するものから、頻度×14日半減の新しさ×アプリ一致率で候補を生成します。保存済み初期配置とは別データです。

記録対象は成功した一括配置・Quick Move・ユーザーが明示的に取り込んだ現状配置です。バックグラウンドでの手動移動の自動観察はありません。機械学習やタイトル内容解析も行いません。

## 保存と互換性

設定と履歴はそれぞれ一時ファイルの同期・前回バックアップ・置換で保存します。既存のショートカット、保存配置、カスタム色は維持し、既知の旧標準色だけを新標準へ移行します。読み込み失敗時は元ファイルを保全します。

モニターの構成キーはID・作業領域座標・寸法・倍率から生成し、列挙順に依存しません。完全一致を優先します。IDが異なっても相対位置・寸法・倍率が一意に対応する構成だけを別候補として表示し、ユーザー操作で読み込みます。接続変更の検出だけでは移動しません。

## 名前・アイコン変更

仮称は`tauri.conf.json`のproductName / title、package / Cargoメタデータ、App.tsxのヘッダー、main.rsのトレイ表示を更新します。アイコンは`src-tauri/icons/`です。データを維持する名称変更ではアプリ識別子`local.windowhub.desktop`を保持してください。商用配布の署名・公証は別作業です。

## フォーカス・権限の再取得

非フォーカスでの非表示はEsc終了と経路を分けます。外側のアプリへ移った場合は復帰処理を行いません。許可がない場合はウィンドウ情報を捏造せず、画面に権限不足を表示します。許可確認・権限不足セッションからの再表示ではAX補助プロセスを再生成します。

半透明はウィンドウを透明にし、CSSの背景色にのみアルファを適用します。macOSのHUD背景効果はTauriのEffectsBuilderを使います。[Tauriのウィンドウ効果](https://v2.tauri.app/reference/config/#windoweffectsconfig)を参照してください。
