# キー操作

入力欄では通常の文字入力を優先します。F6で配置選択と通常のTab操作を切り替えられます。画面を戻っても下書きは保持し、ハブを閉じると未保存の下書きを破棄します。

| 場所 | キー | 操作 |
|---|---|---|
| どのアプリからでも | Ctrl＋Shift＋Space | ハブ表示切替。既存の保存キーがあればそちらを優先 |
| 共通 | Esc | モード・ダイアログを閉じる → 実際の前画面 → Homeから閉じる |
| 共通 | ? | キー操作ガイド |
| 共通 | F6 | 配置選択 / 通常のコントロール操作へ切替 |
| コントロール操作 | Tab / Shift＋Tab、Enter | 項目移動・実行 |
| Home | ↑ / ↓、Enter | メニュー選択・開く |
| Home | A / Q / E / S / K | Arrange / Quick Move / Edit / 保存 / キー設定 |
| Home | T | 外観設定 |
| Arrange | Tab / Shift＋Tab、↑ / ↓ | 対象ウィンドウを切替 |
| Arrange・Edit・Quick | Ctrl＋Tab / Ctrl＋Shift＋Tab | モニターを切替 |
| Arrange | 1〜9 | 選択中のウィンドウを指定領域へ割り当て |
| Arrange | Space / Delete / Backspace | 割り当てを解除 |
| Arrange | / | ウィンドウ名・アプリ名で絞り込み |
| Arrange | R | 比率編集へ |
| Arrange | Enter | プレビュー中の配置を一括適用 |
| Arrange・Edit | Ctrl＋S / Command＋S | 別名保存 |
| Edit | 1〜9 | 編集対象の領域を選択 |
| Edit | V / H | 選択領域を左右 / 上下へ分割 |
| Edit | Delete | 選択領域を削除 |
| Edit | R、[ / ] | 比率編集・分割線の切替 |
| 比率編集中 | 対応軸の矢印 | 5%調整 |
| 比率編集中 | Shift＋矢印 | 1%調整 |
| 比率編集中 | 0 | 子領域数に合わせ等分 |
| 比率編集中 | Enter / Esc | 比率編集モードを終了 |
| Quick | 1 / 2 / 3 / 4 | 左半分 / 右半分 / 最大化 / ネイティブ全画面 |
| Quick | 5 / 6 → 領域番号 | 3列 / 4分割の指定領域へ即配置 |
| 保存一覧 | ↑ / ↓、Enter、/ | 保存配置の選択・読込み・絞り込み |

同じ領域に複数ウィンドウを割り当てると、矩形をずらさず重ねます。Quick Moveの単純操作にはEnterは不要です。初期レイアウト更新や削除は、Tabで明示的な操作へ移動して実行します。
