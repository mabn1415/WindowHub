# UI実装仕様

Homeは配置操作の5項目だけを持つコンパクトなメニューです。検索ランチャー・独自タスクスイッチャー・スローガンは設けません。キーヒント、細い境界、控えめな選択背景で現在位置を示します。モーションは標準160msで、設定とOSの軽減指定に対応します。

Arrangeはウィンドウ一覧と全モニターのプレビューを併置します。番号は選択中モニターの領域を表し、割り当てとStack件数を表示します。未割り当てのウィンドウは動かしません。Enterで現在の一括プレビューを反映します。

Editは選択モニターを拡大し、独立した分割線を表示します。キーボード、比率入力、スライダー、直接ドラッグで同じ分割木を更新します。モニターごとの編集固定と、保存済み初期レイアウトの保護は独立しています。

Quick Moveは起動直前のウィンドウを保持し、番号で即実行します。Savedは固定初期配置・ワークスペース・履歴候補を表示します。履歴候補を読み込んだだけでは移動しません。Settingsは外観、キー操作、履歴と提案の3区分です。

## 初期実装から保留した項目

設定のGeneral詳細（自動起動・任意位置・任意寸法・既定画面）、全機能のキー再割り当て、除外アプリ、バックグラウンド観察、時刻を使う推定、クラウド同期、高度なUndo / Redoは未実装です。構成別レイアウトはSavedとEditで管理します。細かな検証範囲はVERIFICATION.mdを参照してください。

## フォーカスと半透明化の修正

ハブ表示時にネイティブウィンドウとWebViewをフォーカスします。他アプリへの切替で非表示とし、外側へ移ったフォーカスを奪い返しません。自アプリのカラーパネル等は閉じる対象外です。古い非フォーカス処理が次の再表示を閉じないよう、表示セッションを照合します。

背景だけを55〜100%で調整し、macOSではHUD materialの背景ぼかしを併用します。旧設定には82%を補完し、色・起動キー・保存配置は維持します。OSの透明度軽減指定では不透明表示にします。

権限不足・通常ウィンドウがない場合・検索結果がない場合の表示を分離しました。A / Qに権限の説明と操作ボタンを表示し、許可の確認で補助プロセスを再生成します。
